# Licenças incluídas no HTML único

`tensorflowjs-LICENSE` é a licença Apache-2.0 do [TensorFlow.js 4.22.0](https://github.com/tensorflow/tfjs/blob/tfjs-v4.22.0/LICENSE), versão instalada pelo `package-lock.json`.

O build inclui essa licença e `data/fashion-mnist/LICENSE` dentro de `dist/autoencoder.html`, no elemento não visual `third-party-licenses`. Os avisos de licença presentes no JavaScript das dependências também são preservados pelo esbuild.
